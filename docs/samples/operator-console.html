governor の拒否と phase gate は別物として数えている。判定は audit fact の :t を第一根拠にし、:violations の有無では判定しない — 承認者拒否の fact は {:rule :approver-rejected} という violation を自分で載せるので、violation を数えると governor 拒否を過大に数える。分類は governor 自身の :hard? フラグと突き合わせ、食い違ったらビルドを落とす。
